# 地图站图幅和印厂领用单

印厂合成坐标采用本地平面米制。图幅和出血边界使用 [xmin,ymin,xmax,ymax]，左、下含边界，右、上不含边界。

使用 Node.js 22.23.4。执行 `npm ci` 后运行 `npm start`，资料源默认监听本机 4173 端口，可用 `PORT` 指定端口。

`GET /editions` 和 `GET /jobs` 是可浏览的资料入口。`GET /ready` 返回当前发布序号和总发布次数。`PUT /replay` 接受 JSON `{"step":1}`，用于在联调时将来源切到指定发布时刻。发布序号从 0 开始。每次发布只列变化的来源，应答沿用上一轮存在且未被替换的地址。收到 404 并不代表之前的历史资料从业务上被撤回。重新启动服务从第 0 次发布开始。

/editions 返回矩阵参数及版次资源索引链接。origin 是左上原点，列向东加一，行向南加一。area 是可供的专题范围，白地有明确的 blank 声明。compatibleBase 指某个专题版允许用的底图版次。/tiles/.../catalog 中的候选图幅只列可取对象，图幅区域和摘要以目录为准。修订中的 inherits 指明可引用的原图幅；同像素内容仍按目录中的版次承接声明引用。 /jobs 提供图窗与版本指定，/proofs 提供已经交付的取件标识。
同一比例有两套矩阵覆盖时，priority 数值较大的服务区先供图；优先服务区的目录缺件仍按缺件处理。changeArea 是发布方声明的影响范围，不等于目录中的切片边界。未明确继承的切片仍用各版本的独立候选。

运行 `npm test` 可校验资料源实际应答。样本内容存放在 `samples/`，开发时通过各来源的本地地址进行联调。
